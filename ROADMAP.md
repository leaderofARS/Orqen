# ORQEN Roadmap

| Phase | Version | Focus | Status |
| :--- | :--- | :--- | :--- |
| Phase 0 | `0.0.1` | Repository foundation, packaging, config, exceptions, logging, CI, ADRs | **Complete** |
| Phase 1 | `0.1.0` | Single-agent runtime, model/tool abstractions, async execution, streaming | **Complete** |
| Phase 2 | `0.2.0` | Sessions, tasks, typed events, state transitions, SQLite persistence | **Complete** |
| Phase 3 | `0.3.0` | Multi-agent orchestration (sequential, parallel, supervisor, handoffs, graphs) | Planned |
| Phase 4 | `0.4.0` | Durable execution, checkpoints, retries, idempotency, pause/resume, replay | Planned |
| Phase 5 | `0.5.0` | Pluggable memory (session, episodic, semantic) and context management | Planned |
| Phase 6 | `0.6.0` | Profiling-backed Rust native core via PyO3/Maturin and benchmarks | Planned |
| Phase 7 | `0.7.0` | Distributed workers, remote task execution, heartbeats, coordination | Planned |
| Phase 8 | `0.8.0` | Security hardening, OpenTelemetry observability, resource controls, evals | Planned |
| Phase 9 | `0.9.0` | CLI, REST/streaming APIs, MCP/A2A interoperability, Studio preview | Planned |
| Phase 10 | `1.0.0` | Stable public APIs, compatibility guarantees, release automation | Planned |
